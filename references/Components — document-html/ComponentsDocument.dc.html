Document

The document header plus every Markdown element. Markdown tags are styled as plain tags inside .lib-doc, so any renderer’s output works; only the header, code block chrome, callouts, table frame, chart and match wrapper need classes. Sizes come from --doc-* variables that change with the pane width. Previews use .lib-doc--flush to drop the page padding.

Document container and type scale

Sets the reading measure, padding and every size variable. Three steps by pane width: wide (880px and up), medium (560–879px), narrow (under 560px). Needs a size container above it; .lib-doc-pane__scroll is one.

.lib-doc.lib-doc--flush--doc-*
