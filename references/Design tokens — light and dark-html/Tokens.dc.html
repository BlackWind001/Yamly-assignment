Design system

Tokens, light and dark

Every screen reads its colors, type, spacing, radii and motion from tokens.css. Components name a role (--color-text-muted), never a hex, so dark mode is only a second set of values. The app sets data-theme from the OS setting and lets people override it.

Motion

Ease: cubic-bezier(0.2, 0.8, 0.2, 1). Durations: 160ms hover, 320ms fades, 520ms search bar, 560ms pane open and close. All go to 0 when the OS asks for reduced motion.
