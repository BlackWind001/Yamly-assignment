App shell

Two panes in a row. Search fills the window until a result opens; then it shrinks to 440px and the document pane grows in. Reading mode collapses search to zero. Toggle .is-open and .is-reading on .lib-app; the widths animate. The document pane is a size container, so document styles follow its width.
